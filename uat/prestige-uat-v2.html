    Before you start

    • The six demo accounts all use the demo password you saved as APP_SEED_PASSWORD in GitHub.
    • Run the modules in order (A to F). Later tests use the accounts, projects and reports created earlier; a test's Needs line names them.
    • When a test needs two people at once, use a private (incognito) window for the second account.
    • Some tests suspend, disable or ban an account. Each one includes the step that undoes it.
    • Mark Blocked when you can't run a test (for example, an earlier step failed) and say why in the note.
